## Key Architectural Patterns

1. **Riverpod**: Modern, compile-safe state management
2. **Go Router**: Declarative routing configuration
3. **Service Layer**: Separation of concerns with dedicated API/local services
4. **Model-driven**: Strong typing with freezed for immutable models
5. **Provider Pattern**: Dependency injection via Riverpod
6. **Theme Consistency**: Centralized theming for consistent UI

## Development Commands

```bash
flutter pub get              # Get dependencies
flutter gen-l10n             # Generate localizations
flutter pub run build_runner build  # Generate code
flutter run -d <device>      # Run app
flutter test                 # Run unit tests
flutter analyze              # Run analyzer
dart fix --apply             # Auto-fix lints
```
